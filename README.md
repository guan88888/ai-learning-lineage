# 🌌 AI血缘 App

一个专注于AI学习与创作的UniApp应用，采用极简文艺风格设计。

## 📱 功能特性

### 🏠 首页 - 数据舱
- 个性化欢迎界面
- 今日学习进度展示
- 最近项目快速访问
- 学习档案和作品展馆入口

### 📘 学习档案
- AI学习时间线
- 学习统计数据
- AI学习报告生成
- 血缘图谱查看

### 🧩 作品展馆
- 作品网格展示
- 搜索和筛选功能
- 作品详情查看
- 点赞和分享功能

### 👤 个人中心
- 用户信息管理
- AI学习标签
- 个人作品展示
- 学习统计

### 🗺️ AI血缘图谱
- 网络节点关系图
- 学习路径可视化
- 项目关联展示
- 人物关系网络

### 📤 作品上传
- 多类型作品支持
- AI简介自动生成
- 作品分类管理
- 发布流程优化

### 🤖 AI形象生成
- 个性化形象定制
- 多种风格选择
- 历史形象管理
- 实时生成预览

### ⚙️ 系统设置
- 主题模式切换
- 通知设置管理
- 数据导入导出
- 账户安全设置

## 🛠️ 技术栈

- **框架**: UniApp
- **开发语言**: Vue.js
- **样式**: CSS3 + 响应式设计
- **状态管理**: 本地存储
- **UI设计**: 极简文艺风格

## 📦 项目结构

```
AI制作/
├── App.vue                 # 应用入口
├── main.js                 # 主程序文件
├── pages.json              # 页面配置
├── manifest.json           # 应用配置
├── uni.scss               # 全局样式
├── pages/                 # 页面目录
│   ├── home/              # 首页
│   ├── archive/           # 学习档案
│   ├── gallery/           # 作品展馆
│   ├── profile/           # 个人中心
│   ├── lineage/           # 血缘图谱
│   ├── upload/            # 作品上传
│   ├── avatar/            # AI形象
│   └── settings/          # 设置页面
└── static/                # 静态资源
    ├── logo.png           # 应用图标
    └── tab-*.png          # 导航图标
```

## 🚀 快速开始

### 环境要求
- HBuilderX 3.0+
- Node.js 12+
- 微信开发者工具（微信小程序）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd AI制作
   ```

2. **打开项目**
   - 使用HBuilderX打开项目文件夹
   - 等待依赖安装完成

3. **配置项目**
   - 检查 `manifest.json` 中的配置
   - 确认页面路径配置正确

4. **运行项目**
   - 选择运行平台（H5/小程序/App）
   - 点击运行按钮

### 开发调试

1. **H5调试**
   - 选择"运行到浏览器"
   - 在浏览器中查看效果

2. **小程序调试**
   - 选择"运行到小程序模拟器"
   - 使用微信开发者工具调试

3. **App调试**
   - 选择"运行到手机或模拟器"
   - 真机调试或模拟器运行

## 🔧 自定义配置

### 修改主题色
在 `App.vue` 中修改CSS变量：
```css
:root {
  --primary-color: #3498db;
  --secondary-color: #2ecc71;
}
```

### 添加新页面
1. 在 `pages` 目录下创建新页面
2. 在 `pages.json` 中添加页面配置
3. 更新导航逻辑

### 修改数据源
在各个页面的 `data()` 中修改模拟数据，或连接真实API。

## 📦 打包发布

### 小程序发布
1. 在HBuilderX中选择"发行" -> "小程序-微信"
2. 填写小程序信息
3. 上传代码到微信公众平台

### App打包
1. 选择"发行" -> "原生App-云打包"
2. 配置证书和签名
3. 等待打包完成
